# Метрики лабораторных работ

Все длительности в Python измеряются через `time.perf_counter()`, в браузере — через `performance.now()` и Web Animations API. Запуск браузера и сервера в измерение не входит.

## Latency

Время от отправки запроса до получения ответа. Для `/api/join`, `/api/action`, `/api/room` это HTTP round-trip.

## Throughput

Число успешных операций в секунду. Для скачивания — байт/с = `bytes / (duration_ms / 1000)`.

## Response time

Синоним latency для одного запроса. В отчёте указывайте медиану и p95, а не одно случайное значение.

## Animation cycle duration

Интервал одного повторения бесконечной анимации. Для Pulse на скорости 1.0 ожидаемый порядок — около 1200 мс, для Rotate — около 3000 мс. При комбинации измеряйте каждый эффект отдельно.

## Download duration

Время полной загрузки тела ответа. Если `Content-Length` больше фактически полученных байт, статус должен быть `incomplete`, а не `ok`.

## Error rate

`100 * errors / total`. Считайте HTTP 4xx/5xx, timeout и неполную загрузку.

## SSE delivery delay

Разница между отправкой действия и получением соответствующего SSE-сообщения на одном клиенте. Используйте сопоставимые часы: `time.time()` на клиенте измерения.

## Median

Середина упорядоченного ряда. Устойчива к выбросам.

## p95

Значение, ниже которого находятся 95% измерений. Показывает хвост задержек.

## Стандартное отклонение

Разброс вокруг среднего. Считайте по нескольким повторениям одного сценария.

Утилита `calculate_statistics()` возвращает `mean`, `median`, `p95`, `stdev`, `min`, `max`.
